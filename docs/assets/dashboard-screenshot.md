# Dashboard screenshot instructions

The dashboard is generated by the same FastAPI app as the search API, so it
does not require a separate frontend build.

1. Run `./scripts/run_demo.sh` from the repository root.
2. Open <http://127.0.0.1:8000/> in a browser.
3. Capture the status card before the first query (empty cache), submit
   `what explains auroras?`, and wait for the worker to drain.
4. Capture a second view showing the cache coverage and `WARM` search state.

Keep screenshots limited to the tiny synthetic fixture. Do not capture
production document text, credentials, private URLs, or full model paths.
